# Stubble Solutions | Punjab

Static multi-page website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Upload all files in this folder to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.

The homepage is `index.html`. Google Analytics is configured with measurement ID `G-KE79TGJ0NB`.
